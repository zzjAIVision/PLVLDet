# PLVLDet
Inspection of power systems is crucial for ensuring the stability and safety of electricity transmission networks. Timely detection and repair of power line faults, especially under extreme weather or high load conditions, can effectively prevent large-scale outages and economic losses. To improve inspection efficiency, vision-language models have recently achieved remarkable success in open-vocabulary object detection on natural images, offering potential technical support for power line inspection. However, directly applying these models to power line inspection faces several challenges. These include domain-specific terminology, fine-grained defect variations, and severe scale imbalance inherent in transmission line images. To address these issues, we propose a power line vision-language detector (PLVLDet) framework. First, we built a large-scale power line inspection dataset containing 481,912 images and 1,438,073 object-text pairs. The data were collected from 189 transmission lines across six regions in China, covering 32 categories. Next, we combined a domain-adaptive text encoder (PowerBERT) with the YOLOv12 backbone to develop a power-aware vision-language path aggregation network (PA-VL-PAN). This network enables multi-granularity visual-semantic interaction through text-guided cross-attention and strip pooling attention mechanisms. PLVLDet aligns object region embeddings with category text embeddings via region-text contrastive learning, achieving efficient cross-modal feature fusion. Experimental results show that PLVLDet achieves excellent performance in zero-shot detection, reaching 38.5% mAP without any target-domain supervision about 11 times higher than the strongest baseline, Grounding DINO-B (3.5%). After fine-tuning, PLVLDet achieves an overall mAP of 80.8% and 68.9% mAP on unseen defect categories, outperforming all compared methods by 5.4-14.5 points. Meanwhile, PLVLDet remains computationally efficient, with only 18.6M parameters and 45.2 GFLOPs.
